# Excel Formulas & Functions Fundamentals

This project demonstrates essential Excel formulas and functions using a sample sales transaction dataset.

## Functions Demonstrated
- **VLOOKUP:** Retrieve product prices using Product IDs.
- **XLOOKUP:** Retrieve product names.
- **IF:** Classify sales performance as High or Low.
- **SUMIFS:** Calculate sales based on specific criteria.
- **COUNTIFS:** Count transactions matching criteria.
- **LEFT and RIGHT:** Extract characters from text.
- **TRIM:** Remove unnecessary spaces.

### Workbook Contents
1. `Transactions` — Sales records and calculated results.
2. `Product Lookup` — Product IDs, names, categories, and prices.
3. `Formula Practice` — Practical formula examples.
4. `Formula Notes` — Explanations and use cases.

### Tools Used
- Microsoft Excel for the web
- Excel formulas and functions

### Objective
To develop practical spreadsheet skills for data handling, lookup operations, calculations, and basic sales analysis.
